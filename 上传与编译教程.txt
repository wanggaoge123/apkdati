================================================================
  手写听写守护 APP · GitHub 桌面端上传与云端编译教程（纯文字）
================================================================

【前置说明】
- 本仓库是标准 Android Studio 项目，但你不装 Android Studio / JDK / SDK。
- 上传到 GitHub 后，GitHub Actions 自动在云端编译，生成"未签名 APK"。
- 你只需用「GitHub 桌面端」完成：新建仓库 → 上传 → 看编译 → 下载 APK。

------------------------------------------------------------
第一步：在 GitHub 网页上新建仓库
------------------------------------------------------------
1. 打开 https://github.com ，登录你的账号。
2. 点右上角「+」→「New repository（新建仓库）」。
3. 仓库名随便起，例如：hidden-dictation-app
4. 选「Public（公开）」或「Private（私有）」都行。
5. 关键：不要勾选「Add a README file」等初始化选项（因为你本地已有完整项目）。
6. 点「Create repository（创建仓库）」。
7. 创建后页面会显示一个仓库地址，形如：
   https://github.com/你的用户名/hidden-dictation-app.git
   复制这个地址备用。

------------------------------------------------------------
第二步：用 GitHub 桌面端把本项目上传
------------------------------------------------------------
1. 打开 GitHub 桌面端（GitHub Desktop），登录同一账号。
2. 菜单「File」→「Add Local Repository（添加本地仓库）」。
3. 路径选你电脑上的文件夹：
   C:\Users\Administrator\Desktop\安卓弹窗答题
   （这个文件夹里已经有 settings.gradle、app\ 等完整内容）
4. 如果桌面端提示"这不是一个 Git 仓库"，点「Create a repository（创建仓库）」，
   然后「Publish to GitHub（发布到 GitHub）」，选择第一步建的仓库。
   若已是 Git 仓库，则直接「Publish（发布）」。
5. 发布时：
   - 选第一步建好的仓库（或新建同名仓库）；
   - 不要勾「Keep this code private」以外多余项；
   - 点「Publish Repository」。
6. 上传完成后，回到 GitHub 网页该仓库，能看到所有文件（含 .github/workflows/build.yml）。

------------------------------------------------------------
第三步：查看云端编译进度
------------------------------------------------------------
1. 在 GitHub 网页该仓库，点顶部「Actions」标签。
2. 你会看到一条名为「构建未签名APK」的工作流正在运行（黄色圆点 = 运行中）。
3. 点进去可看实时日志：检出代码 → 装 JDK17 → 编译 assembleRelease。
4. 编译通常需要 3~6 分钟（首次拉依赖较慢）。
5. 绿色对勾 = 成功；红色叉 = 失败（点开看日志，把报错发给我排查）。

------------------------------------------------------------
第四步：下载成品 APK
------------------------------------------------------------
1. 编译成功后，在 Actions 工作流页面右侧（或底部）有「Artifacts（产物）」区。
2. 找到名为「hidden-dictation-apk」的下载项，点它下载 zip。
3. 解压得到：app-release-unsigned.apk（这就是未签名 APK）。
4. 把 APK 传到手机安装即可。

------------------------------------------------------------
第五步：手机安装与权限（重要）
------------------------------------------------------------
1. 手机允许「未知来源安装」（设置→安全→允许未知来源）。
2. 安装后打开：因为本 APP 桌面无图标、无主界面，
   需到 手机设置 → 无障碍 → 找到「手写听写守护」并开启。
   （开启无障碍即自动启动后台计时与听写弹窗）
3. 首次会循环弹出 4 项权限引导，逐项授予：
   悬浮窗、忽略电池优化、后台活动(自启动)、无障碍。
4. 累计亮屏达到设定时长（默认 3 分钟，可选 1/2/3/5），
   任意界面（含全屏游戏）上层弹出手写听写窗。
   写对自动关闭并重置计时；写错持续锁死，直到写对。

------------------------------------------------------------
常见问题
------------------------------------------------------------
Q：编译失败，日志报 "Could not find ... gradle-8.9"？
A：CI 会自动下载 Gradle，无需本地安装；若卡住多半是网络，重试一次即可。

Q：APK 安装提示"签名冲突/未签名"？
A：本项目产出未签名 APK（需求要求）。直接安装即可，部分手机需先卸载旧版。

Q：想改触发时长/词库？
A：词库与权重在 app/.../db/DictationRepository.kt 的种子列表；
   触发时长在 ScreenTimeTracker.TRIGGER_MINUTES_OPTIONS。改完重新推送即重新编译。

Q：桌面端提示 "large files" 或推送慢？
A：本项目无大文件，正常几秒到几分钟。
